# Εισαγωγικό μάθημα Προγραμματισμού στο Διαδίκτυο 2026

Ασκήσεις με HTML, CSS και JavaScript.

## Αρχεία

| Αρχείο | Περιγραφή |
|---|---|
| `intro_web.html` | Σελίδα με ένα κουμπί. Όταν το πατάς, εμφανίζεται το μήνυμα «Καλή ακαδημαϊκή χρονιά!». |
| `intro_web2.html` | Σελίδα με το κουμπί Έκπληξη. |

## Πώς τρέχουν

Άνοιξε οποιοδήποτε αρχείο `.html` με έναν browser (π.χ. Chrome, Firefox). Αρκεί ένα διπλό κλικ.

## Τεχνολογίες

- HTML
- CSS
- JavaScript
